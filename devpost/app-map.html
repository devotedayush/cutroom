PROJECT MAP / LOCAL VIDEO EDITING

Follow one file.
Understand the whole editor.

This guide points to the implemented code. It is a reference for your review; it does not claim that you have completed a learning activity.

Local File→Asset + Clip decisions→Canvas + audio→Local video download

1. Open a source

src/media/import.ts → importMedia

The browser reads a selected File through BlobSource. Metadata and a thumbnail become an Asset. The footage is never sent to a processing server.

2. Describe the edit

src/model.ts → createClip, splitClip, locateClip

A Clip points to a source asset and its in/out times, title, framing and volume. Splitting changes the decisions; it does not rewrite the source file.

3. Make the pixels

src/render.ts → drawComposition

Preview and export share the same framing and title renderer. This makes a visible edit comparable to the rendered result.

4. Finish the file

src/media/export.ts → exportProject, capTimeline

WebCodecs encodes frames and trimmed audio. A local remux removes encoder end-padding. The browser then exposes a Blob download and a native video preview.

What gets saved?

src/storage.ts → serializeProject / parseProject saves validated edit decisions and source metadata. It excludes source bytes and temporary blob URLs. Keep the originals to relink them. The production service worker caches only shipped app files, not footage or projects.

A useful practice to reuse

Choose a visible outcome before adding features. Here, a five-second test edit has known colors, source times and tones. Reopen the exported video and inspect those results; a passing build alone cannot prove the media pipeline works.

Optional review activity: change one title, trace it from App.tsx through model.ts to render.ts, export, and compare the resulting frame. Your own reflection remains yours to write.

Boundaries

Desktop Chrome is the tested target. One linear sequence, a 180-second cap, browser-supported codecs, source audio, titles and three aspect ratios. User review and the final Devpost submission remain separate steps.
